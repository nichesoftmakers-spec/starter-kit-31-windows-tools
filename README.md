## 💡 はじめに

日々の実務や制作現場で、「巨大なソフトを導入するほどではないけれど、手作業でやると毎回15分〜30分が溶けていく単純作業」に時間を奪われていませんか？

- 「送られてきたCSVを開いたら文字化けして記号だらけ」

- 「PDFの個人情報を今すぐ黒塗りしたいが、有料ソフトがない」
- 「社外秘の機密データだから、無料のWeb変換サイトにはアップロードできない」

こうした現場の切実なお悩みを、**ドラッグ＆ドロップ3秒で解決する特化型WindowsポータブルGUIツール**をこれまで31本開発してきました。
本リポジトリでは、その**全31ツールの無料お試し版（Lite版）を1つにまとめたスターターパック**を無料公開しています。

## ⚡ 4大特徴

1. **ゼロインストール・環境構築不要**:  
   Pythonのインストールやコマンドプロンプト操作は一切不要。Windows公式Embedded Pythonを内包しているため、ZIPを解凍してダブルクリックするだけで即起動します。
2. **完全オフライン動作（高セキュリティ）**:  
   外部サーバーへの通信は物理的に一切行いません。社外秘データや未公開素材も安全に処理できます。
3. **総合ランチャー「Master Launcher」同梱**:  
   31本を迷わず探せるダッシュボード（リアルタイム検索・カテゴリ別タブ・ワンクリック起動）が付属しています。
4. **ずっと無料（0円）**:  
   お試し版として回数制限や機能制限がありますが、ずっと無料でご利用いただけます。

1. ダウンロードした `bundle_31_starter_lite_Windows.zip` を右クリックして「すべて展開」
2. 展開されたフォルダ内の **`MasterLauncher.vbs`** をダブルクリック
3. 総合ランチャー画面が開いたら、使いたいツールの「起動」ボタンを押すだけ！

## 🛠️ 技術スタック・アーキテクチャ
- **Backend / UI**: Python 3.11 (Embedded Python) + Streamlit
- **Native Wrapper**: VBScript + Batch (No console window)
- **Signal / Data Processing**: NumPy, SciPy, Pandas, PyMuPDF, OpenCV, Pillow
